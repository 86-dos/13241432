## 📄 Описание каждого файла

### Program.cs
**Назначение:** Точка входа приложения, DI конфигурация  
**Размер:** ~25 строк  
**Ключевые части:**
- Конфигурация из `appsettings.json` и env переменных
- Регистрация всех Services
- Логирование

### Services/BotWorker.cs
**Назначение:** HostedService для фонового опроса Telegram API  
**Размер:** ~70 строк  
**Ключевые части:**
- `StartAsync()` — инициализирует TelegramBotClient
- `ExecuteAsync()` — вечный цикл опроса
- Обработка ошибок с SelfRepairService

### Services/CommandHandler.cs
**Назначение:** Обработчик всех пользовательских команд  
**Размер:** ~300+ строк  
**Команды (11+):**
- `/start` — приветствие
- `/register` — регистрация
- `/profile` — профиль
- `/leave` — выход
- `/act` — действие с генерацией ответа
- `/addbudget` — админ команда
- `/remember` — сохранить заметку
- `/memory` — показать заметки
- `/history` — история действий
- `/prices` — цены
- `/help` — помощь

### Services/Database.cs
**Назначение:** SQLite БД + Dapper ORM  
**Размер:** ~250 строк  
**Таблицы (4):**
- `users` — профили игроков
- `history` — история действий
- `memories` — заметки
- `error_logs` — ошибки

### Services/AIService.cs
**Назначение:** ИИ-генерация RP ответов  
**Размер:** ~150 строк  
**Возможности:**
- OpenAI ChatGPT интеграция
- Fallback шаблоны (20+ вариантов)
- Учёт памяти при генерации

### Services/SelfRepairService.cs
**Назначение:** Логирование ошибок и автоисправление  
**Размер:** ~120 строк  
**Возможности:**
- Логирование в БД, файл и консоль
- Генерация suggestion через OpenAI
- Отслеживание исправленных ошибок

### CSharpGeoRP.csproj
**Назначение:** Конфиг проекта  
**Зависимости:**
- `Telegram.Bot` — API Telegram
- `Dapper` — микро-ORM
- `Microsoft.Data.Sqlite` — SQLite
- `Microsoft.Extensions.*` — DI, конфиг, логирование
- `OpenAI` — (опционально) интеграция

### appsettings.json
**Назначение:** Конфигурация приложения  
**Параметры:**
- `TelegramToken` — токен бота
- `OpenAIApiKey` — ключ OpenAI (опционально)
- `AdminIds` — массив ID админов
- `DatabasePath` — путь к БД
- `Logging` — уровни логирования

### Dockerfile
**Назначение:** Сборка Docker образа  
**Стратегия:** Двухэтапная (build + runtime)
- Сокращает финальный размер образа
- Использует MS official образы

### docker-compose.yml
**Назначение:** Локальный запуск через Docker  
**Сервисы:**
- georp-bot — основной контейнер
- Волюмы для data и logs
- Переменные окружения
